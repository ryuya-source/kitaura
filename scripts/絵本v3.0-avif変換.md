# 絵本v3.0 の PNG を AVIF に変換する

## 手順

### 1. ターミナルで実行

```bash
cd /Users/ishikawatatsuya/Desktop/タスク管理/scripts
npm install
node images-to-avif.mjs "/Users/ishikawatatsuya/Downloads/絵本v3.0"
```

### 2. 出力先

変換された AVIF は次のフォルダに保存されます。

```
/Users/ishikawatatsuya/Downloads/絵本v3.0/avif/
```

### PNG だけ変換したい場合

いまのスクリプトは **png, jpg, jpeg, webp, gif, heic** をまとめて変換します。  
PNG だけにしたい場合は、絵本v3.0 フォルダ内の PNG 以外を一時的に別フォルダに退避してから上記コマンドを実行してください。

---

## 共有された 11 枚の絵本イラスト（assets）を AVIF に変換する

Cursor にアップロードした 11 枚の PNG を AVIF に変換し、**ワークスペース内の `絵本-avif` フォルダ**に出力する場合：

```bash
cd /Users/ishikawatatsuya/Desktop/タスク管理/scripts
npm install
node convert-assets-to-avif.mjs
```

- 入力: `~/.cursor/projects/Users-ishikawatatsuya-Desktop/assets/` 内の PNG  
- 出力: `タスク管理/絵本-avif/*.avif`

assets フォルダのパスが違う場合は、第1引数で指定できます。

```bash
node convert-assets-to-avif.mjs "/任意の/assets/フォルダパス"
```

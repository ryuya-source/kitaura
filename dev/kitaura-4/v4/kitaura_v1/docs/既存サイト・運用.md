# 既存サイト・運用

## 既存サイト（本番）の構成

| 項目 | 内容 |
|------|------|
| **URL** | http://kitauralakeside.com/ |
| **ドメイン** | 独自ドメイン（kitauralakeside.com） |
| **サーバー** | ロリポップ（Lolipop） |
| **CMS** | WordPress |
| **表示** | ロリポップサーバー上に配置した WordPress のファイルを読み込んで表示 |

## 補足

- 本リポジトリ（kitaura_v1）は新サイト／リニューアル用の Next.js アプリケーションです。
- 既存の本番サイトは上記のとおり WordPress + ロリポップで運用されています。
- 独自ドメインは http://kitauralakeside.com/ で運用中です。

# ドメイン移行手順：kitauralakeside.com → Vercel（kitaura_v1）

kitauralakeside.com（WordPress + ロリポップ）を kitaura_v1（Next.js + Vercel）に一発で切り替えるための手順書です。

---

## 進捗

| Phase | 内容 | 状態 |
|-------|------|------|
| Phase 1 | Vercel にプロジェクト接続・デプロイ | **完了** |
| Phase 2 | ドメイン事前認証（SSL先行発行） | 未着手 |
| Phase 3 | DNS 切り替え（本番反映） | 未着手 |
| Phase 4 | 事後確認・旧サイト停止 | 未着手 |

---

## Phase 2: ドメイン事前認証（切り替え前日〜当日）

**目的**: DNS を切り替える前に SSL 証明書を先行発行し、切り替え直後の「保護されていない通信」警告を防ぐ。

### 手順

1. **Vercel ダッシュボード** を開く
   - 対象プロジェクト → **Settings** → **Domains**
   - 入力欄に `kitauralakeside.com` を入力し「Add」

2. **Vercel が指示するレコードを確認する**
   - TXTレコードの値が表示される（例: `_vercel.kitauralakeside.com` に設定する値）
   - Aレコード・CNAME の値も表示されるが、**この時点では TXT だけ追加する**

3. **ムームードメインの DNS 設定画面** を開く
   - ムームードメイン（https://muumuu-domain.com/）にログイン
   - 対象ドメイン → 「DNSレコード設定」

4. **TXT レコードを追加する**

   | 種別 | ホスト名 | 値 | 備考 |
   |------|---------|-----|------|
   | TXT | `_vercel` | Vercel が表示した値をコピペ | SSL先行発行用 |

   **注意: これ以外のレコード（A / CNAME / MX）は絶対に変更しない**

5. **TTL を短縮する**（可能であれば）
   - TTL を 300秒（5分）に変更
   - 当日の DNS 切り替えが早く反映されるようになる

6. **Vercel 側で認証完了を待つ**
   - Vercel ダッシュボードの Domains 画面で、ステータスが「Verified」になれば完了
   - 通常 数分〜30分

7. **SSL 証明書の発行を確認**
   - Verified 後、Vercel が自動で SSL 証明書を発行する
   - これで Phase 2 完了

---

## Phase 3: DNS 切り替え（本番反映 -- 一発で切り替え）

**目的**: ムームードメインの A レコードをロリポップから Vercel に書き換え、kitauralakeside.com で新サイトを表示する。

### 作業前チェック

- [ ] Phase 2 の Vercel 認証が「Verified」になっている
- [ ] SSL 証明書が発行済み
- [ ] 新サイト（xxx.vercel.app）で表示・動作に問題がない
- [ ] お問い合わせフォームのテスト送信が成功している

### 手順

1. **ムームードメインの DNS 設定画面** を開く

2. **以下のレコードを変更する**

   | 種別 | ホスト名 | 変更前（ロリポップ） | 変更後（Vercel） |
   |------|---------|-------------------|-----------------|
   | **A** | `@`（空欄） | ロリポップの IP | `76.76.21.21` |
   | **CNAME** | `www` | ロリポップ指定の値 | `cname.vercel-dns.com` |

3. **絶対に変更してはいけないレコード**

   | 種別 | 理由 |
   |------|------|
   | **MX** | メール（info@kitauralakeside.com）が止まる |
   | **TXT**（_vercel） | Phase 2 で追加済み。消さない |
   | **TXT**（SPF等） | メール認証に必要な場合がある |

4. 設定を保存する

5. **反映を待つ**（数分〜30分。TTL を 300秒にしていれば早い）

---

## Phase 4: 事後確認

### 切り替え直後（5分〜30分後）

- [ ] **スマホのモバイル回線** + **シークレットモード** で `https://kitauralakeside.com` にアクセス
- [ ] 新サイト（kitaura_v1）が表示される
- [ ] アドレスバーに鍵マーク（SSL）が表示される
- [ ] お問い合わせフォームからテスト送信 → `info@kitauralakeside.com` にメールが届く
- [ ] メールの送受信が通常どおり動作する（MX が変わっていないことの確認）

### 24〜48時間後

- [ ] PC・スマホ・別の Wi-Fi 環境など、複数の環境で新サイトが表示される
- [ ] 旧サイト（WordPress）をロリポップの管理画面から停止する（任意）

---

## 重要注意事項

### メールについて

ロリポップのメール（info@kitauralakeside.com）は **MX レコードで管理されている**。今回変更するのは **A レコード（Web サイトの向き先）だけ** なので、メールには一切影響しない。ただし MX レコードを誤って削除・変更するとメールが届かなくなるため、**MX は絶対に触らない**。

### 新旧サイトの混在期間

DNS 反映中の数時間は、アクセスする人によって旧サイト（WordPress）と新サイト（kitaura_v1）のどちらかが表示される。この期間中：

- 旧サイトのお問い合わせフォームを停止するか、「新サイトへ移行中」の案内を出す
- 問い合わせデータの抜け漏れを防ぐ

### 反映確認のルール

「設定したのに変わらない」はほとんどがブラウザキャッシュ。反映確認は必ず：

- **スマホのモバイル回線**（Wi-Fi ではなく 4G/5G）
- **シークレットモード**（Safari: プライベートブラウズ、Chrome: シークレットウィンドウ）

### ロールバック（万が一の戻し方）

新サイトに重大な問題が見つかった場合、ムームードメインの DNS 設定画面で：

- A レコードを Vercel の IP（`76.76.21.21`）からロリポップの IP に戻す
- CNAME も元に戻す

これだけで旧サイト（WordPress）に切り戻せる。TTL を短縮していれば 5〜30分で戻る。
